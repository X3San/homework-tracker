# 作业本 · 作业与提交情况管理

给大学生用的一个单页小工具：记录每门课有哪些作业、什么时候交、做到哪一步了，以及每本作业本现在在你手上还是已经交上去了。

纯静态网页，没有后端、没有数据库、不需要安装任何东西。数据保存在**你自己手机的浏览器**里（localStorage），不联网、不上传。

## 网址

部署完成后可以在这里打开（把仓库名换成你自己的即可）：

```
https://X3San.github.io/homework-tracker/
```

手机上建议用 Safari / Chrome 打开后「添加到主屏幕」，之后点图标就能全屏打开，和 App 一样。

## 功能

**科目**

- 新建、重命名、改颜色、删除科目
- 卡片上显示这门课有多少项作业、多少项待提交、几本作业本在手，以及提交完成率

**作业**

- 每门课下添加、编辑、删除作业
- 记录**提交日期**，自动显示「今天截止 / 明天截止 / 还有 N 天 / 已逾期 N 天」
- 记录**完成情况**：未完成 → 进行中 → 已完成 → 已提交
- 点作业左边的状态标签可以直接循环切换状态，切到「已提交」时自动记下今天的日期
- 可加备注（比如「需要打印」「小组作业」）

**作业本**

- 每门课下登记作业本，比如「高数作业本（蓝皮）」「数据结构实验本」
- 标记每本**在我手上**还是**已提交**，可记录提交日期和交给谁
- 点状态标签即可在「在我手上 / 已提交」之间切换

**总览与筛选**

- 顶部四个数字：待提交、已逾期、今日截止、作业本在手，点一下就能筛出对应内容
- 筛选条：全部 / 待办 / 今日 / 逾期 / 已提交

**其他**

- 导出 / 导入 JSON 备份
- 浅色 / 深色 / 跟随系统
- 支持离线打开，断网也能用

## 怎么用（第一次上手）

1. 点右下角 **+**，新建一个科目，比如「高等数学」。
2. 在科目卡片里点 **添加作业**，填作业内容、提交日期、完成情况。
3. 想改状态时，直接点作业左边的彩色标签。
4. 点卡片里的 **作业本** 标签页，登记作业本并标记在谁手上。
5. 不知道从哪下手的话，在设置里点 **添加示例数据**，先看看效果。

## 部署到 GitHub Pages

Windows 上一键部署（需要已安装 Git 和 GitHub CLI，并执行过 `gh auth login`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

脚本会依次完成：初始化本地仓库 → 提交 → 创建 GitHub 仓库 → 推送 → 开启 Pages，最后打印网址。

想换仓库名：`.\deploy.ps1 -RepoName 你的名字`。

也可以完全手动：

1. 在 GitHub 新建一个 **public** 仓库，名字比如 `homework-tracker`（不要勾选添加 README）。
2. 本机执行：

```bash
git init
git add -A
git commit -m "init: 作业本"
git branch -M main
git remote add origin https://github.com/X3San/homework-tracker.git
git push -u origin main
```

3. 仓库页面 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存，等 1 分钟左右生效。

## 更新网页内容

改完 `index.html` 后：

```bash
git add -A
git commit -m "更新"
git push
```

GitHub Pages 会自动重新发布。如果手机上看到的还是旧版，把 `sw.js` 里的 `CACHE` 版本号改成 `hw-tracker-v1.0.1` 再推一次；或者手机浏览器里清一下该站点的数据。

## 数据说明（重要）

- 数据只存在打开网页的那台设备的浏览器里，**不会同步**：手机和电脑各记各的。
- 清除浏览器数据、卸载浏览器、使用无痕模式，都会导致记录丢失。重要内容请在设置里**导出备份**。
- 导出的 JSON 文件可以用「导入备份」恢复到任何设备。
- 换新手机：先导出，再在新手机上打开网页导入。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部界面和逻辑（HTML + CSS + JS 都在里面） |
| `manifest.webmanifest` | 添加到手机主屏幕的配置 |
| `sw.js` | 离线缓存 |
| `icon.svg` | 图标 |
| `deploy.ps1` | Windows 一键部署脚本 |

## 想换图标

`icon.svg` 可以直接用文本编辑器改颜色或图形。如果要生成 iOS 上显示更标准的 PNG 图标，可以在浏览器里打开 `index.html` 后截图，或把 SVG 转成 180×180 和 512×512 的 PNG，替换后同步修改 `manifest.webmanifest` 里的 `icons`。

## 许可

随便用，改成自己需要的版本即可。
